```ts
import { gmail } from "@waterlock/gateway/providers/gmail";

gmail({ credentials });
```

- Actions: Gmail API method ids, e.g. `gmail.users.messages.send`. Full list: [codegen-report.md](https://github.com/waterlockcc/waterlock/blob/main/src/providers/gmail/codegen-report.md). See [Actions](/docs/concepts/actions).
- `r.context` on `messages.send`, `drafts.create`, `drafts.update`: `recipients`, `recipient_domains`, `subject`, `text`, `html`, `attachments`, decoded from the message.
- `r.context` on `drafts.send`: only `draft_id`; every other field is `null`. Gmail sends the stored draft, so the gateway can't see who it goes to or what it says. A rule that allows `drafts.send` allows sending any draft as it stands, including ones written outside the gateway.
- Harness: stock `@googleapis/gmail` with `rootUrl` set to the gateway. See the [Quickstart](/docs/getting-started#quickstart).

## Errors

Gateway errors use Google's error format ([AIP-193](https://google.aip.dev/193)), the same body Gmail sends for its own [403 errors](https://developers.google.com/workspace/gmail/api/guides/handle-errors#403-errors):

```json
{
  "error": {
    "code": 403,
    "message": "Error for waterlock proxy: You can only send email to yourself.",
    "status": "PERMISSION_DENIED",
    "errors": [
      {
        "message": "Error for waterlock proxy: You can only send email to yourself.",
        "domain": "waterlock.cc",
        "reason": "policyDenied"
      }
    ],
    "details": [
      {
        "@type": "type.googleapis.com/google.rpc.ErrorInfo",
        "reason": "POLICY_DENIED",
        "domain": "waterlock.cc",
        "metadata": { "action": "gmail.users.messages.send" }
      }
    ]
  }
}
```

With `@googleapis/gmail`, the thrown error has `code` and `status` set to `403` and the prefixed `message`. To tell a gateway denial from one of Gmail's own, check the domain and reason:

```ts
const e = err.response?.data?.error?.errors?.[0];
if (e?.domain === "waterlock.cc" && e.reason === "policyDenied") {
  // denied by the gateway's policy
}
```

When a `deny` rule matched, `metadata.rules` lists its id (e.g. `"#2"`). `reason` is the [error code](/docs/concepts/request-flow#errors) in camelCase (`policy_denied` becomes `policyDenied`). `status` is the matching Google status: `INVALID_ARGUMENT` (400, 413), `PERMISSION_DENIED` (403), `NOT_FOUND` (404), `UNAVAILABLE` (502).
