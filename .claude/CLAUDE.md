# waterlock

## Wiki (`wiki/`)

- Links to repo files use the `main` branch: `https://github.com/waterlockcc/waterlock/tree/main/<dir>` for folders, `https://github.com/waterlockcc/waterlock/blob/main/<file>` for files. Never a feature branch or commit SHA. We assume that
  the PR is going to be merged so links become available when they are actually in main.

## Creating PRs

- You must follow the rules in .github/pull_request_template.md
- Do not add the 'Generated by' line, the PR was a collaborative approach not a generation. I don't think statement
  is correct.
- You must create the branch from origin/main. If the branch is already created, verify that you took a pull from 
  origin/main into your branch before you get back to the user.
